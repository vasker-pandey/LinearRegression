# Linear Regression Analysis: Diabetes & California Housing

This repository explores the fundamentals of linear regression by implementing predictive machine learning models on two classic datasets from `scikit-learn`. The goal is to contrast the simplicity of single-variable modeling against the complexity of multi-variable real-world data.

## 📊 Datasets Explored

1. **Diabetes Dataset (Simple Linear Regression)**
   * **Focus:** Predicting disease progression based on individual health metrics (e.g., isolating Body Mass Index).
   * **Key Concepts:** Finding the best-fit line ($y = mx + b$), understanding residuals, and plotting 2D trends.

2. **California Housing Dataset (Multiple Linear Regression)**
   * **Focus:** Predicting median house values across districts using multiple economic and geographic features (e.g., income, location, room averages).
   * **Key Concepts:** Handling multi-dimensional coefficients, feature correlation, and model evaluation metrics like Mean Squared Error (MSE) and $R^2$ score.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib / Seaborn
